# Sight Reading Adventure · 识谱冒险

当前版本：ver 1.4（每次推送 +0.1，版本号写在 `index.html` 顶部的 `VERSION` 常量，主页标题下可见）

单文件网页小游戏：`index.html`，无任何依赖，双击即可在浏览器打开（手机、电脑均可）。

## 第一版（v1）包含
- Lv1–7 识谱核心课程（高音谱表 → 低音谱表 → 大谱表），Lv8–12 为占位、后续版本开放
- 每局 20 题，五线谱在上、可弹钢琴键盘在下；键盘只显示本级音域（两侧各留 2 个白键），键位自动加宽，Lv7 为 C2–C6 全键盘，Web Audio 合成钢琴音
- 计分：≤1.2 s ⚡150 / ≤3 s 100 / 更慢 50；Combo 5 / 10 / 20 额外奖励；开「键名」提示时不给速度奖励
- 答错：错键变红、正确键轻闪，不直接报答案，自动进入错题本
- 局末 Boss Battle 错题复仇：间隔重复，每个错音连续答对 3 次才消掉
- 长期薄弱音符库：错误率高的音及其相邻音在正常训练中自动加权出现
- 晋级：最近 10 局共 200 题正确率 ≥ 98% 且平均反应达标（各级 3.0 / 2.5 / 2.0 s）
- 主页：熟练度、今日最佳连击、平均识谱速度、识谱速度趋势、容易认错、今日任务
- 三个提示开关：键名（琴键上标字母）、音名（音符右上角标键名）、彩键（当前音符对应的琴键直接亮起）；开任一提示该题不给速度奖励
- Lv7 起可开 Blind Mode（隐藏中央 C 标记）；Lv3 起默认关闭键名
- 数据存浏览器 localStorage（键 `sra_v1`）
- 横屏：安卓 / 电脑浏览器第一次点击自动进入全屏（顶栏 ⛶ 可切换）；iPhone 请用 Safari「添加到主屏幕」后从桌面打开，即为无边框全屏（含 manifest.json 与图标）
